## Télécharger

| Système | Fichier |
|---|---|
| Windows 10/11 x64 | `Pokerace-v0.2.2-windows-x64.exe` |
| Linux x64 | `Pokerace-v0.2.2-linux-x64` (`chmod +x` puis `./Pokerace-v0.2.2-linux-x64`, Mono requis : `sudo apt install mono-complete`) |

Remplace la 0.2.1 : la fiche du joueur sur le site doit afficher la version **0.2.2**.

## Nouveauté

**ID Dresseur** : le client envoie l'ID Dresseur et le nom lus dans la sauvegarde. Le site s'en sert pour « Plus un Pokémon d'échange » : un Pokémon reçu prend le dresseur du joueur et obéit, même s'il est seul dans l'équipe.

## Vérification

`SHA256SUMS.txt` donne l'empreinte de chaque fichier.
