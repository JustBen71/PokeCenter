## Télécharger

| Système | Fichier |
|---|---|
| Windows 10/11 x64 | `Pokerace-v0.2.0-windows-x64.exe` |
| Linux x64 | `Pokerace-v0.2.0-linux-x64` (`chmod +x` puis `./Pokerace-v0.2.0-linux-x64`, Mono requis : `sudo apt install mono-complete`) |

Un seul fichier : il ouvre le formulaire, télécharge et vérifie BizHawk 2.11.1 au premier lancement, puis lance le jeu et le client. La ROM n'est pas fournie : Pokémon Émeraude **français** (`.gba`).

**Formulaire** : Serveur `37.187.181.38` · Port `80` · Pseudo = nom du compte sur le site · Code du salon = code du lobby (en bas du menu du site). Le compte doit avoir rejoint le lobby sur le site avant.

**Remplace l'ancien lanceur** : la fiche du joueur sur le site doit afficher la version **0.2.0**. Avec la 0.1.0, les combats et les pas ne déclenchent pas les nouveaux passifs.

## Nouveautés

**Fin de Run**
- Toute défaite (blackout, combat commandité perdu, équipe K.O.) termine la Run ; une nouvelle Run démarre et le jeu redémarre seul, après sauvegarde des 3 dernières parties perdues.
- Un Pokémon K.O. part dans la boîte PC.

**Tableau des combats** (« premier arrivé, premier servi ») : équipes à affronter en zone sûre, récompense calculée ou fixée, roues qui ajoutent un combat de niveau proche.

**Passifs** : les 27 passifs sont actifs. Nouveaux : Prime de dresseur, Compagnon fidèle, Dernier debout, Alchimiste, Chasseur de trésors, Marathonien, ADN instable, Maître des types, Résurrection, Mutagène, Prime de risque, Héritier des légendes. Le client lit maintenant les combats (victoire contre un dresseur, K.O., fin de combat) et les pas.

**Roues**
- Nouveaux gages : objet gagné ou perdu, transfert de Pokémon, niveau ±, malédiction du Magicarpe.
- Une roue peut rester hors boutique ; « Lancer à tous » ; roue automatique toutes les N minutes.
- Le joueur qui tire choisit lui-même la cible d'un gage (combat commandité, vol…) ; se choisir soi-même = combat miroir.
- Ticket gris pour les roues neutres.

**Comptes** : rôle administrateur par mot de passe du serveur (« Se connecter en admin » dans le menu du profil).

**Corrections** : la fenêtre « Changer d'avatar » ne déborde plus de l'écran.
