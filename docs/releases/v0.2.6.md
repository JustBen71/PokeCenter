## Télécharger

| Système | Fichier |
|---|---|
| Windows 10/11 x64 | `Pokerace-v0.2.6-windows-x64.exe` |
| Linux x64 | `Pokerace-v0.2.6-linux-x64` (`chmod +x` puis `./Pokerace-v0.2.6-linux-x64`, Mono requis : `sudo apt install mono-complete`) |

Remplace la 0.2.5 : la fiche du joueur sur le site doit afficher la version **0.2.6**.

## Nouveauté

**Reprendre une sauvegarde automatique (après un crash).** Le formulaire du lanceur a une nouvelle ligne « ↺ Reprendre une sauvegarde automatique ». Elle liste les copies faites toutes les 5 minutes (3 gardées), avec leur heure. Après confirmation, BizHawk démarre directement sur la copie choisie, sauvegarde en jeu comprise. Ce qui a été joué depuis est perdu.

Les copies sont maintenant rangées dans `launcher/autosaves`. Celles des versions 0.2.3 à 0.2.5, gardées dans le dossier BizHawk, apparaissent aussi dans la liste.

## Vérification

`SHA256SUMS.txt` donne l'empreinte de chaque fichier.
