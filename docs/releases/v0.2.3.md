## Télécharger

| Système | Fichier |
|---|---|
| Windows 10/11 x64 | `Pokerace-v0.2.3-windows-x64.exe` |
| Linux x64 | `Pokerace-v0.2.3-linux-x64` (`chmod +x` puis `./Pokerace-v0.2.3-linux-x64`, Mono requis : `sudo apt install mono-complete`) |

Remplace la 0.2.2 : la fiche du joueur sur le site doit afficher la version **0.2.3**.

## Nouveautés

**Copies de secours automatiques** : toutes les 5 minutes, la partie en cours est copiée (état complet de l'émulateur + sauvegarde en jeu) dans le dossier `PokeraceAutosaves` de BizHawk. Seules les 3 dernières copies sont gardées ; une copie ratée ne supprime jamais les précédentes.

- Linux : `~/.config/Pokerace/launcher/BizHawk-2.11.1/PokeraceAutosaves/`
- Windows : `%LOCALAPPDATA%\Pokerace\launcher\BizHawk-2.11.1\PokeraceAutosaves\`

Chaque copie contient `game.State` (à charger dans BizHawk : *File > Load State > Load Named State*) et `game.SaveRAM` (la sauvegarde en jeu).

**Sauvegarde en jeu écrite chaque minute** : BizHawk écrit maintenant la sauvegarde sur le disque toutes les minutes, plus seulement à sa fermeture. Un plantage ne fait plus perdre la sauvegarde.

## Vérification

`SHA256SUMS.txt` donne l'empreinte de chaque fichier.
